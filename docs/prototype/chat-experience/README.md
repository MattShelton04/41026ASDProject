# Chat interaction studies (scratch prototypes)

Open `index.html` in a browser, or serve this directory on loopback. A local scratch copy is
available at `Temp/chat-experience/` during review. These authored files are checked in so the
comparison is reproducible; they are not mounted into the application or a deployment.

Five directions use one simulated lifecycle: Fieldnote, Research desk, Focus, Contextual sidecar
and Research canvas. All use the existing shared Fieldbook colour tokens. Try source
inspection, follow-up, context search, ambiguous results, missing guidance, connection recovery,
failed checks and cancellation. Context identifiers and addresses are synthetic. Timings are
simulation timings, not provider benchmarks. No network calls, external dependencies or storage.

Native dialogs, labelled controls, live announcements and reduced-motion styling are included.
The production plan and measured runtime findings live in `docs/design/chat-experience-plan.md`.
