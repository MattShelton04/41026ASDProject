Try the whole story

The unhappy paths deserve
the same care.

Open a study, send the suggested question, inspect a source, and ask a follow-up. Change the scenario to try unavailable guidance, interrupted updates, a failed check, or an ambiguous address. Stop a running turn to try cancellation.

Review lenses: Which wait feels most reassuring? How easily can you understand a claim's source? Which layout would you return to every day?

All records, answers, timings and service activity in these studies are simulated. No model, publisher or application API is called. These are design spikes, separate from the production interface.
