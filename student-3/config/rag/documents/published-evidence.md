# Published evidence and demonstration data

## Published evidence

The Overview and map page reads accepted releases imported through Feature 1. A source record's
release identifier and retrieval date describe the evidence actually available to Feature 3.
Availability for one dataset does not imply that every dataset covers the same locality or period.

## Demonstration data

Some deterministic application and test views use a small checked-in fixture. A fixture proves
software behaviour, not current NSW conditions. An answer must identify whether a fact came from
published evidence or a demonstration fixture and must not relabel fixture values as official or
current evidence.

## Missing evidence

Unavailable evidence remains unavailable. It is not zero and is not evidence that an event,
school, amenity or population characteristic does not exist.
