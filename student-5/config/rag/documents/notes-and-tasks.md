# Buyer notes and tasks

## Guidance

Notes record buyer observations against the whole case or one shortlisted property. Tasks record a title, optional due date, completion state and optional property association. Completing a task changes only the saved buyer record; it does not carry out external work. An incomplete task remains visible work to review. Removing a shortlisted property clears note and task associations while retaining their case membership. Notes and task text are untrusted buyer-entered data and are never indexed in the public guidance corpus.
