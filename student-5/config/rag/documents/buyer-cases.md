# Manage buyer cases

## Guidance

A buyer case records a search name, optional budget range, NSW target suburbs and preferences. New cases are active; paused and closed are the other supported statuses. Open a case to edit it. Changes require the current version; if another edit wins, refresh before saving again. Deleting a case requires confirmation and removes its related shortlist, notes and tasks. These are buyer-recorded preferences, not proof of affordability or suitability.
