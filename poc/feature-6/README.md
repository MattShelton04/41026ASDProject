# Feature 6 integration POC

This is a local-only integration laboratory. It is not a sixth allocated student feature and it
does not claim to implement the assessed Features 2–5. It exercises the public Shared and Feature 1
boundaries by composing representative sales, place, due-diligence and buyer-workspace workflows.

The POC never imports Feature 1 production code, opens its PostgreSQL database, mounts its artifacts,
or changes the planned status of Features 2–5. Property identity is read over Feature 1 HTTP APIs;
accepted sales, crime and school products arrive through the documented publication callback or
accepted-release reconciliation. Planning, hazard, strata and building evidence remains explicitly
unavailable because Feature 1 has no registered products for those domains.

The complete architecture, demonstration flow and friction register are maintained in
`docs/architecture/feature-6-integration-poc.md`.
