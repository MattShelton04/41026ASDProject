# Reading a property record

A property record page opens from Property search. The top shows the address, locality, postcode, identity status and when the record was last updated. Property at a glance repeats the canonical address and status; the map shows the recorded point from G-NAF.

## Research available

Lists the published datasets that currently have evidence linked to this property, such as NSW address records and ABS SEIFA 2021, with the version each came from. A dataset that is not listed has no linked published evidence here; that is not the same as a negative result.

## Sale history

Matched sales from the published NSW sales data, newest first, with contract date, price and how the sale was matched. "No published sale history" means no matched sale was found, not that the property has never sold.

## Area context

SEIFA 2021 scores for the suburb or locality. These describe the area, not the property.

## Sources and identifiers

The G-NAF identifiers, address aliases, match details and the dataset versions used for this page. Use this tab to trace where each value came from.

## Asking about a property

"Ask about this property" opens the assistant with this property attached, so it can look up the record directly instead of searching by address.
