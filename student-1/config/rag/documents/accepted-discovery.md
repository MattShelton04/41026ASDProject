# Searching for an address

Property search looks up NSW addresses in the currently published G-NAF address records. Candidate data from an update in progress is never searched.

## How to search

Enter any combination of street number, street name, suburb and postcode. Punctuation and letter case do not matter. Results are ranked by how the text matched: an exact address, an address starting with your text, an address containing it, or a close spelling match. Broad searches such as a suburb name return many results; add a street name or number to narrow them.

## When more than one address matches

Unit, shop and street addresses are separate records, and similar street names exist in many suburbs. When results are ambiguous, choose the address yourself. The assistant should list the choices and ask rather than pick one.

## When nothing matches

Check the spelling, try fewer words (for example the street and suburb without the number), or search by postcode. A missing result means the address is not in the published records; it is not evidence that the property does not exist. See "NSW address records (G-NAF)" for common reasons.

## Sales and addresses

Sales are linked to addresses by exact address match. An unmatched sale is still kept in the sales data; it is not evidence that the sale did not happen.
